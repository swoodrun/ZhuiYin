工具调用超时或读到旧数据时，业务可能已经完成，Agent 看到的却是失败或空结果；它报告成功时，也未必有足够证据。追因把工具调用、数据库状态和最终报告放在同一条实验链中，便于回看和复核。

## 运行程序

1. 进入 `program/`，双击 `追因.exe`。
2. 保留完整 `_internal` 目录；电脑需安装 Microsoft Edge WebView2 Runtime。
3. 无需安装 Python，也无需模型密钥即可查看界面、预览导入和运行规则检查。
4. 真实 Agent 测试需在工作台填写兼容 API 地址、模型名称和有效密钥。

## 运行源码

```text
cd source/zhuiyin
C:\Python314\python.exe -B server.py --port 8766
```

浏览器打开 http://127.0.0.1:8766。后端只监听本机回环地址。
