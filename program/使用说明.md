# 使用说明

追因 Windows 桌面版

1. 完整解压后双击“追因.exe”，前端直接显示在软件窗口中，不跳转外部浏览器。无需安装 Python；运行前需安装 Microsoft Edge WebView2 Runtime。请保留完整的 `_internal` 目录。
2. 真实 Agent 实验需在工作台填写模型 API 地址、名称和密钥；密钥不保存。配置后可进入批量测试。请求上限、费用保护额度和三项单价统一在工作台“调用预算与费用”设置，批量与对比沿用。
3. 点击窗口右上角关闭按钮会停止本版后台服务并退出；有实验或下载运行时，按提示先停止或等待完成。
4. 历史、日志、内嵌页面缓存和运行临时文件保存在 EXE 旁的“追因数据”文件夹。请解压到可写目录；移动程序时一起移动该文件夹，更新时保留。
5. 输入文件通过软件内文件选择框或拖入操作导入；下载结果时在软件弹出的保存框选择位置。
6. 软件通过 WebView2 在内部窗口显示本机工作台，系统默认浏览器设置不影响显示。
7. 包内不含原项目历史、API 密钥、研究台账或留待实测的新样本；原网页端数据需另行迁移。
8. 需要独立保存位置时，运行：`追因.exe --data-dir "D:\追因数据"`；退出时使用相同参数并加 `--stop`。

当前只支持内置设备借用/工单创建 Agent，任意外部 Agent 接入尚未开放。
