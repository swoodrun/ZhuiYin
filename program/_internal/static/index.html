预算和缓存价格如何计算
三项单价单位均为人民币元 / 百万 token，可填 0；均不超过 1000000，最多 6 位有效小数（末尾的 0 不计）。价格不填时只记录请求数和服务商返回的用量，费用显示未知。启用费用保护额度时，必须填写“缓存未命中”和“输出”单价；缓存命中单价可留空，按未命中单价保守估算。
费用保护按填写的价格与用量估算，不能保证服务商账单绝对不超额。这里填写的价格用于本机估算与发送前的保守预留，不改变服务商实际账单；请按自己的模型与计费方案填写。是否命中缓存由服务商决定，不能在这里强制开关。缓存用量缺失时不会按 0 费用处理。
每次模型调用前检查剩余额度；不足时停止并保留已有结果。单次实验包括故障精简及防护对照，批量测试覆盖所有任务，对比测试覆盖所有组合。测试连接也会请求模型，独立限 1 次，并采用这里的单价和费用保护额度。

如何制作批量导入包
一行一个任务，改好模板就能上传。单个 CSV 可以直接测试；多个文件也可以压缩成 ZIP。


↓ 下载完整练习模板 ZIP设备借用 CSV工单创建 CSV


查看制作步骤与字段说明


  1. 打开模板。下载上方 CSV，用 Excel 或 WPS 打开；下载 ZIP 时先解压。
  2. 每行填写一个任务。保留第一行表头，复制数据行可增加任务；修改业务内容，并给每行填写不同的“请求编号”。
  3. 填写故障。不需要故障就留空；多种故障用分号隔开，例如“提交后响应丢失；读取过期状态”。
  4. 保存文件。另存为“CSV UTF-8（逗号分隔）”。不要把 XLSX 直接改名成 CSV。
  5. 上传并核对。直接选择 CSV，或把多个 CSV 压缩成普通 ZIP 后上传。确认预览中的任务、重复、冲突和错误，再点击“开始全部测试”。


设备借用模板
“设备名称”填要借的设备；“库存”填非负整数；“借用数量”填正整数。
例如：会议投影仪，库存 3，借用 1。
工单创建模板
“业务场景”固定填 ticket；“工单标题”填要创建的内容；“优先级”可填 low（低）、normal（普通）、high（高）、urgent（紧急）。


通用字段怎么填写示例
请求编号每个独立任务使用不同编号，整包避免重复。my-test-001、my-test-002
种子可以统一填 42，暂时不需要调整。42
故障留空表示无故障；多个故障用中文或英文分号隔开。提交后响应丢失；读取过期状态


支持的故障：提交后响应丢失、读取过期状态、响应内容缺失、工具调用延迟、写入前超时、未提交却返回成功、业务内容损坏。


保留模板表头，不新增答案、备注等列。模型地址、密钥和指令在工作台配置，不放进导入包。文件数量与大小上限见上传区说明。


练习模板共 5 个场景，均已通过导入预览检查，仅供练习使用。真实 Agent 批量测试会按每个场景运行 4 种防护方式，共 20 次任务执行；任务次数不等于模型请求次数。预览和下载模板不调用模型；开始真实测试后才会发出模型请求。规则检查与日志静态检查不调用模型。








导入预览
同一请求的 JSON 与 CSV 副本会标为重复并跳过，不会增加独立测试数。压缩包中的答案、元数据与辅助记录不作为新测试运行；无效文件保留错误记录。

使用方法
  1. 配置 Agent。在工作台填入模型服务、模型名称和密钥，核对可用工具及完整指令。
  2. 设置任务与故障。例如库存3台、借用1台，正常应只有一条记录且库存剩2台。
  3. 运行与查看。先看 Agent 实际操作、数据库结果和报告，再看同一错误复现与故障精简。没有复现错误也会如实保留。
真实 Agent 主流程包括原始执行、故障精简与组合防护对照；不自动执行下方规则检查。四种防护方式的真实多轮对照位于“对比测试”页。密钥不会保存；连接测试也会调用模型。

限制说明
工作台运行真实模型 Agent；使用方法中的规则检查不调用模型。设备和工单在本机模拟。工具业务参数由系统自动填写；模型只决定操作与恢复，不测试参数生成。独立检查是可用工具，不强制拦截未经核验的成功报告。内置用例只覆盖选定场景。日志只做静态检查，不执行代码。结构化凭据会打码隐藏；自由文本需自行去除秘密。模型需手动配置，密钥不会保存。用量缺失时，费用显示为未知。预算不足会提前停止并保留结果。
